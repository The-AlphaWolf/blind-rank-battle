## 🌟 Overview

**BLIND RANK BATTLE** is an adrenaline-fueled strategic character ranking game and automatic battle simulator. Draw characters one-by-one from a massive database of **1,700+ iconic combatants across 10 distinct universes** without knowing who comes next. 

Place them into ranked slots: your top-ranked champions become your defenders, while your bottom-ranked picks turn against you as attackers! Once the draft ends, watch the automated battle engine resolve combat turn-by-turn with power affinities, ability triggers, weaknesses, critical strikes, and status effects.

## 🕹️ How to Play

1. **Configure Your Battle:** Choose your categories (or play with all 10 universes) and select your squad size (e.g. 10 slots).
2. **Rank Blindly:** A random character is revealed. Decide their slot number (1 to 10) immediately—once placed, their rank is locked!
3. **The Twist:**
   - **Slots 1–5:** Your **Defending Team** 🛡️
   - **Slots 6–10:** Your **Attacking Enemy Squad** ⚔️
4. **Commence Battle:** Watch both sides face off in an intense simulation to see if your defenders can survive the onslaught of your attackers!

## 🛠️ Local Development

To run the game locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/The-AlphaWolf/blind-rank-battle.git
   cd blind-rank-battle
   ```

2. **Open `index.html`:**
   - Simply double-click `index.html` to open it in any modern browser, or
   - Serve using VS Code Live Server, or
   - Run a simple local server:
     ```bash
     # Python 3
     python -m http.server 8000
     ```
   - Navigate to `http://localhost:8000` in your web browser.
